# Integration with `GpioController` and device bindings
The following demonstrates how to use the MCP2221A's GPIO functionality via [System.Device.Gpio.GpioController](https://learn.microsoft.com/dotnet/api/system.device.gpio.gpiocontroller) and control various devices using the device bindings provided by [Iot.Device.Bindings](https://www.nuget.org/packages/Iot.Device.Bindings/).

- [GpioController_ShiftRegister](./GpioController_ShiftRegister/) 74HC595 shift register
- [GpioController_TM1637](./GpioController_TM1637/) TM1637 LED driver
